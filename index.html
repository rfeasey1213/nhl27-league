Set up the league

This runs once. You become the host: you create everyone's username and password.

1. Make an access key on GitHub

  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it nhl27-league and pick the longest expiration offered.
  3. Under Repository access, choose Only select repositories and pick nhl27-league.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Click Generate token and copy it.

2. Create the league

Standings

2 pts for a win, 1 for an overtime or shootout loss. Ties broken by wins, goal difference, then goals for. Everyone plays everyone twice, once at home and once away.
