Set up the league

This runs once. You become the host: you create everyone's username and password.

1. Make an access key on GitHub

  1. Open github.com/settings/tokens/new.
  2. Name it nhl27-league, pick the longest expiration, and tick only public_repo.
  3. Click Generate token and copy it.

2. Create the league
